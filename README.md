# Ada Portfolio

Ready for GitHub Pages.

## Upload
Upload the CONTENTS of this folder to the root of `adasusaatci.github.io`:
- index.html
- style.css
- script.js
- articles/

Then wait for GitHub Pages to deploy.

## Customize
Search `index.html` for:
- YOUR_EMAIL_HERE
- `href="#"` for GitHub and LinkedIn
- `YOUR PHOTO`

Replace these with your own information. The article HTML files contain placeholders for your full writing.
